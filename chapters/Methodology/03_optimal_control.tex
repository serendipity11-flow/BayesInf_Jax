\section{Optimal Control}
\label{sec:methods:control}

From a general perspective, the state-estimation methods discussed in the previous section transform one temporal sequence into another. These two sequences are related through the underlying dynamical system. The same perspective also applies to the control framework: in an \ac{MPC} setting, the simulation model maps the current state and control input to the next state; a control policy finds the next control input from the target and observations; a path planner generates a sequence of future control inputs from the current state and the relevant history. In this section, we will discuss how to integrate the normalizing-flow-based methods into control frameworks.

The four methods are applied differently in a control framework due to their different characteristics. 
\begin{enumerate}
    \item \textbf{AmortizedSeqFlow} is based on training a desired mapping offline and then directly using the trained model online. Thus, the optimization process of finding the optimal control input is performed implicitly offline by training the posterior of control inputs conditioned on the observed and reference signals. Once trained, the control input can be inferred directly. Thus, it is approprate to use AmortizedSeqFlow to replace the optimization loop in a standard \ac{MPC} framework.
    \item \textbf{LatentSSMFlow} applies a linear state space model in the latent space, which is natural to adapt it to capturing the underlying dynamics of the system. The system states are then modeled stochastically by taking the previous states and inputs as conditions, i.e., $\boldsymbol{x}_t \leftarrow (\boldsymbol{x}_{t-1}, \boldsymbol{u}_{t-1})$. Then, the control input is optimized in a stochastic \ac{MPC} framework.
    \item \textbf{NormFlowSDE}, likewise, can also model the system dynamics and be integrated into a stochastic \ac{MPC} framework, such as \ac{MPPI}.
    \item \textbf{CondStochInt} is a conditional generative model, which can be used as a control policy or path planner to generate sequential control inputs conditioned on the current system states and observation histories. We compare its performance with \ac{DPPO} \citep{ren2024diffusionpolicypolicyoptimization, black2024trainingdiffusionmodelsreinforcement}.
\end{enumerate}

Due to the different characteristics and the modeling capabilities of the four methods, they are also validated with different experiments, which are suitable for their respective control frameworks as well.

\subsection{AmortizedSeqFlow in MPC}
Recall the Section~\ref{sec:mpc}, a standard \ac{MPC} requires solving a constrained trajectory optimization problem at every single environment time step. This is highly compute-intensive and can cause execution latencies. At every time step for updating the system, a sequence of future control inputs are supposed to be optimized based on the observed and referred signals. This mapping from observations and references to control inputs can be learned by the AmortizedSeqFlow. It bypasses this iterative optimization loop entirely and effectively "amortizes" the optimization cost.

As shown in Figure~\ref{fig:amortized_seq_flow_control}, the whole \ac{MPC} block including the optimization and model, together with the state estimation are replaced by a two-head conditional normalizing flow. One head extracts information from the reference signals, while the other head is a similar condition network for the history observations. The normalizing flow transforms a latent sequence to the control input sequence under the conditions from both heads. In this setting, only the average input sequence is applied and the posterior uncertainty is not considered.

Once the action chunk $\boldsymbol{u}_{0:H-1}$ is generated, the first control action $\boldsymbol{u}_{0}$ is extracted and applied to the system (the physical robot or plant). The system interacts with environmental disturbances/noise $\epsilon$ and advances one step, producing a new observation $\boldsymbol{y}_1$. The history buffer is then updated ($\boldsymbol{y}_{...:0}\rightarrow [\boldsymbol{y}_{...:0},\boldsymbol{y}_1]$) and ready for the next control cycle.

Comparing with the classical \ac{MPC}, AmortizedSeqFlow offers several advantages. First of all, by replacing the iterative optimization loop with a single feedforward pass through the normalizing flow, the controller has a constant execution time, which helps prevent control loop delays. Secondly, AmortizedSeqFlow integrates a state estimator with the controller, which utilizes information from history observations as much as possible. Thirdly, the normalizing flow implicitly learns the system's dynamic constraints from offline training data, ensuring that the generated control input sequences are dynamically feasible for the system to execute.

\paragraph{Validation with Lane Tracking}
We evaluated the proposed AmortizedSeqFlow as a behavioral clone of an MPC controller on a synthetic lane-tracking task governed by a rear-axle kinematic bicycle model. The vehicle state was $[e_{y,t},e_{\psi,t}]^\top$, where $e_{y,t}$ denotes the lateral tracking error and $e_{\psi,t}$ denotes the heading error relative to the reference path. The steering angle $\delta_t$ was the control input. The simplified discrete-time error dynamics were
\begin{align}
e_{y,t+1} &= e_{y,t}+\Delta t\,v\sin(e_{\psi,t}),\\
e_{\psi,t+1} &= \text{wrap}\,[e_{\psi,t}+\Delta t(\frac{v}{L}\tan\delta_t-v\kappa_t)],
\end{align}
with sampling time $\Delta t=0.1\,\mathrm{s}$, constant velocity $v=8\,\mathrm{m}\,\mathrm{s}^{-1}$, wheelbase $L=2.7\,\mathrm{m}$, and steering constraint $|\delta_t|\leq35^\circ$. Here, $\kappa_t$ denotes the curvature of the reference path at time step $t$. At the prescribed speed, the vehicle travelled approximately $0.8\,\mathrm{m}$ during each control step. The lane centerlines were defined as functions of longitudinal position by summing three sinusoids. The amplitude, spatial frequency, and phase of each sinusoid were sampled uniformly from $[0.15,0.9]\,\mathrm{m}$, $[0.025,0.09]\,\mathrm{rad}\,\mathrm{m}^{-1}$, and $[-\pi,\pi]$, respectively.

Training examples included recovery conditions with lateral errors sampled uniformly from $[-1.2,1.2]\,\mathrm{m}$ and heading errors sampled uniformly from $[-0.25,0.25]\,\mathrm{rad}$. Expert demonstrations were generated by a constrained nonlinear MPC controller using the same nonlinear error dynamics as the evaluation plant. We generated 12,000 examples and randomly divided them into training, validation, and test sets in proportions of 80\%, 10\%, and 10\%, respectively. Each sample contained a $2\,\mathrm{s}$ history of tracking errors, a $1.5\,\mathrm{s}$ reference-path preview, and the corresponding $1.5\,\mathrm{s}$ future control sequence. Accordingly, AmortizedSeqFlow was trained to map a 20-step error history and a 15-step reference-path preview to a 15-step control sequence.

For the closed-loop evaluation, we used previously unseen winding paths and simulated 300 control steps, corresponding to $30\,\mathrm{s}$. We conducted two experiments. The first compared the controllers from three representative initial conditions under a lateral-measurement noise standard deviation of $0.12\,\mathrm{m}$. The second examined sensitivity to lateral-measurement noise with standard deviations of $0$, $0.12$, and $0.24\,\mathrm{m}$; in this experiment, all controllers started from $(e_{y,0},e_{\psi,0})=(0.55\,\mathrm{m},0.12\,\mathrm{rad})$. AmortizedSeqFlow was executed deterministically by setting each component of the latent input to its median value. We compared it with linear and nonlinear finite-horizon MPC controllers. For both controllers, a linear Kalman filter was applied to estimate the states from noisy error measurements. The estimator received only the noisy lateral deviation and inferred the unobserved heading error through the vehicle dynamics. All methods received identical reference paths and noise realizations.

Figure~\ref{fig:amortized_seq_flow_vs_mpc_trajectories} compares the closed-loop lateral tracking errors of AmortizedSeqFlow, linear MPC, and nonlinear MPC over a $30\,\mathrm{s}$ simulation with a measurement-noise standard deviation of $0.12\,\mathrm{m}$. AmortizedSeqFlow exhibits smoother, lower-amplitude fluctuations for the nominal and moderate initial conditions. For the large initial displacement, it produces a pronounced initial overshoot but recovers quickly. The trajectories of the linear and nonlinear MPC controllers overlap almost completely in all three cases. Overall, AmortizedSeqFlow provides competitive tracking, particularly for the nominal and moderate initial conditions. This behavior is consistent with its offline training: recovery is most effective for initial conditions that are well represented in the training distribution.

\subsection{LatentSSMFlow in Stochastic MPC}
A stochastic \ac{MPC} relies heavily on a surrogate dynamics model to project future system behaviors over a prediction horizon $H$. When the underlying physical system is highly nonlinear or exhibits multi-modal stochasticity, standard deterministic or Gaussian dynamics models fail. This method resolves this by modeling transitions using a LatentSSMFlow. 

\subsubsection{LatentSSMFlow as a Surrogate Model in Stochastic MPC}
As shown in Figure~\ref{fig:latentssmflow_smpc}, LatentSSMFlow is trained as a probabilistic, control-conditioned transition model, $p_\varphi\left(\mathbf{x}_{t+1}|\boldsymbol{x}_{t-H+1:t},\boldsymbol{u}_{t-H+1:t}\right)$, using a state-history length of $H$. The model predicts the state increment $\Delta\mathbf{x}_{t+1}=\mathbf{x}_{t+1}-\mathbf{x}_t$ then adds the increment to the current state. The stochastic \ac{MPC} iteratively chooses candidate inputs $\boldsymbol{u}_{0:H-1}$ through the dynamics model to predict next-step states $\hat{\boldsymbol{x}}_{1:H}$ and select the optimal sequence that tracks a reference trajectory $\boldsymbol{y}^r_{1:H}$. 

For stochastic MPC with LatentSSMFlow, the control objective function can be written as an expectation over the stochastic state trajectories generated by the learned flow:
\begin{equation}
    J(\boldsymbol{u}_{t:t+H-1};\boldsymbol{x}_t)
    =\mathbb{E}_{\boldsymbol{x}_{t:t+H}\sim
    p_\varphi(\cdot|\boldsymbol{x}_{t-H+1:t},\boldsymbol{u}_{t:t+H-1})}
    \;\left[
    \sum_{h=0}^{H-1}
    \ell(\boldsymbol{x}_{t+h},\boldsymbol{u}_{t+h})
    +\ell_f(\boldsymbol{x}_{t+H})
    \right],
    \label{eq:stochastic_mpc_objective}
\end{equation}
where $p_\varphi$ is the trajectory distribution learned by the LatentSSMFlow, $\ell$ is the stage cost function, and $\ell_f$ is the terminal cost function. The expectation is approximated by sampling multiple trajectories from the learned flow model. 

The optimization problem is solved using a sampling-based method, such as \ac{CEM}, a sampling-based stochastic optimization algorithm suitable for non-convex and derivative-free problems \citep{rubinstein1999cem}. At each MPC step, CEM maintains a Gaussian distribution over length-$H$ control sequences. Candidate sequences are sampled and evaluated by propagating multiple stochastic trajectories through LatentSSMFlow. The cost of each trajectory is estimated by averaging the stage and terminal costs across the sampled particles by LatentSSMFlow.

Besides, risk-aware loss and input smoothness regularization terms can be added to the cost function. In the risk term, the variance of the predicted states by LatentSSMFlow is penalized to avoid high-variance trajectories. In the smoothness term, the difference between consecutive control inputs is penalized to avoid abrupt changes in the control input sequence.

CEM then refits its sampling distribution to the $N$ lowest-cost elite sequences. After several iterations, the control input of the optimized mean sequence over the $N$ elite sequences is applied, and the procedure is repeated at the next time step.

\subsubsection{Validation with Obstacle Avoidance}
The obstacle-avoidance experiment considers the Clearpath Jackal unmanned ground vehicle (UGV), a compact four-wheel, differential-drive research platform \citep{clearpath_jackal,clearpath_jackal_manual}. This study is a simulation experiment parameterized after the Jackal robot. The simulated state is:
\begin{equation}
    \boldsymbol{x}_t=[p_{x,t},p_{y,t},\sin\psi_t,\cos\psi_t,v_t,\omega_t]^\top,
\end{equation}
where $(p_{x,t},p_{y,t})$ is the position, $\psi_t$ is the heading angle (yaw angle), $v_t$ and $\omega_t$ are the linear and angular velocities. The control input is:
\begin{equation}
    \boldsymbol{u}_t=[v_t^{\mathrm{cmd}},\omega_t^{\mathrm{cmd}}]^\top,
    \quad \text{s.t.}\quad
    0\leq v_t^{\mathrm{cmd}}\leq1.0\,\mathrm{m}\,\mathrm{s}^{-1},\;
    -1.5\leq\omega_t^{\mathrm{cmd}}\leq1.5\,\mathrm{rad}\,\mathrm{s}^{-1}.
\end{equation}

The simulation runs at $\Delta t=0.1\,\mathrm{s}$. The robot is approximated by a circular footprint of radius $r_{\mathrm{rob}}=0.27\,\mathrm{m}$, with a pre-defined safety margin of $r_{\mathrm{safe}}=0.18\,\mathrm{m}$. Training trajectories were generated using a higher-fidelity differential-drive simulation, which contains dynamics that are not represented in a nominal model. The simulated effects included motor lag, payload-dependent inertia, one- or two-step command delay, spatially varying terrain traction, asymmetric wheel slip, lateral slip, external longitudinal disturbance, and process noise. The relevant parameters were randomized independently between episodes so that the learned transition represented a distribution of plausible Jackal dynamics.

The training set contained 128 simulated episodes of 100 transitions each. Commands were held constant for 5 simulation steps to produce piecewise-smooth but persistently exciting trajectories. Linear-velocity commands covered approximately the feasible ranges. Each episode began at the origin with a yaw angle sampled uniformly from \([-\pi,\pi]\). Episodes were divided into training, validation, and test subsets using an approximately 80/10/10 split. The LatentSSMFlow was trained with a history length of $H=5$ and a prediction horizon of $H=10$. 

Besides the in-domain evaluation, generalization was also evaluated without retraining on four \ac{OOD} plants. The in-domain plant used parameter values within the training ranges, whereas the OOD cases introduced an excessive command delay, a substantially heavier payload, previously unseen lateral and yaw disturbances, or a simultaneous combination of low traction, severe slip, delay, payload, and external disturbances.

\paragraph{Closed-Loop Optimal Control}
The closed-loop task requires the robot to travel from a neighborhood of the origin to the goal $(p_{x,\text{goal}}, p_{y,\text{goal}})=(4.0,0.0)\,\mathrm{m}$. Two circular obstacles are placed at
\begin{equation}
    \boldsymbol{o}_1=(2.0,0.0),\qquad r_1=0.42\,\mathrm{m},\qquad\boldsymbol{o}_2=(3.0,0.7),\qquad r_2=0.28\,\mathrm{m}.
\end{equation}
The first obstacle lies directly between the start and goal and therefore forces the controller to select a path around it. The second obstacle restricts the upper route and makes the choice of avoidance direction sensitive to the initial pose. Collision checking accounts for the robot footprint: a collision occurs when the distance from the robot center to an obstacle boundary is below $0.27\,\mathrm{m}$. A safety violation occurs below the combined robot radius and safety margin, $r_{\mathrm{rob}}+r_{\mathrm{safe}}=0.45\,\mathrm{m}$. The control objective was to track a reference trajectory while avoiding obstacles, with the cost function penalizing deviations from the reference path, control effort, and proximity to obstacles.

Eight closed-loop in-domain episodes were evaluated in Figure~\ref{fig:latentssmflow_cem_comparison_dashboard}. Initial lateral positions alternated between $p_{y}=-0.35\,\mathrm{m}$ and $p_{y}=0.35\,\mathrm{m}$, while the initial yaw varied from $-0.175$ to $0.175\,\mathrm{rad}$. This produced trajectories approaching the obstacle configuration from different initial poses. The trained LatentSSMFlow was compared with a nominal model in a stochastic \ac{MPC} framework using \ac{CEM} for optimization. Both controllers reached the goal in all eight episodes without a collision or safety-margin violation. In terms of computation time, LatentSSMFlow controller requires approximately 11 times more computation time per MPC command and can be improved to 22 times faster than the nominal model controller on CPU.

\subsection{NormFlowSDE in MPPI}
\ac{MPPI} is a sampling-based stochastic \ac{MPC} method that estimates the optimal control update from a path integral rather than differentiating the dynamics or the cost function \citep{williams2017mppi}. This property makes it particularly suitable for NormFlowSDE: the learned model already generates continuous-time stochastic state paths by numerical integration, and these paths can be used directly as the Monte Carlo rollouts required by MPPI. Thus, the same model represents both the nonlinear mean dynamics and the non-Gaussian process uncertainty considered during control.

\subsubsection{NormFlowSDE as a Surrogate Model in MPPI}
For control, Equation~\ref{eq:flow_sde} is adapted by conditioning both the drift and the flow-based stochastic increment on the control input:
\begin{equation}
    d\boldsymbol{x}_t
    = f_\varphi(\boldsymbol{x}_t,\boldsymbol{u}_t,t)\,dt
    + g_\phi(\boldsymbol{\epsilon};
        \boldsymbol{x}_t,\boldsymbol{u}_t,t)\sqrt{dt},
    \qquad
    \boldsymbol{\epsilon}_t\sim\mathcal{N}(\boldsymbol{0},\boldsymbol{I}).
    \label{eq:controlled_normflowsde}
\end{equation}
Here, $f_\varphi$ learns the conditional drift, whereas the invertible normalizing flow $g_\phi$ transforms Gaussian distribution into state- and input-dependent stochastic increments. The stochastic term can model complex uncertainty and also the unmodeled dynamics residual. 

The model is trained offline from states and inputs trajectories $\mathcal{D}=\{(\boldsymbol{x}(t),\boldsymbol{u}(t))\}$, which can be collected from the real system or a high-fidelity simulator. A two-stage training procedure is used: first, the drift network $f_\varphi$ is trained to minimize the one-step prediction error using \ac{MSE}, and then the flow network $g_\phi$ is trained together with the drift network using the loss function Eq.~\ref{eq:normflowsde_loss}. After training, the NormFlowSDE model can be applied in an \ac{MPPI} framwork. During deployment, the current state initializes the SDE solver, and sampled trajectories generate an ensemble of possible future paths for every candidate input sequence.

\subsubsection{Model Predictive Path Integral control}
At control time $t$, MPPI maintains a nominal sequence
$\boldsymbol{U}_t=(\boldsymbol{u}_t,\ldots,\boldsymbol{u}_{t+H-1})$ over a horizon $H$. It draws $K$ perturbation sequences
$\delta\boldsymbol{U}_t^{(k)}$, commonly from a zero-mean Gaussian distribution with covariance $\boldsymbol{\Sigma}_u$, and forms the candidate inputs
\begin{equation}
    \boldsymbol{u}_{t+h}^{(k)}
    =\Pi_{\boldsymbol{U}}\;\left(
    \boldsymbol{u}_{t+h}+\delta\boldsymbol{u}_{t+h}^{(k)}\right),
    \qquad h=0,\ldots,H-1,
\end{equation}
where $\Pi_{\boldsymbol{U}}$ enforces the feasible input set. Each candidate is integrated through Equation~\ref{eq:controlled_normflowsde}. With $M$ independent dynamics realizations per candidate, its expected trajectory cost is approximated by
\begin{equation}
    \widehat{J}_k
    =\frac{1}{M}\sum_{m=1}^{M}\left[
    \sum_{h=0}^{H-1}
    \ell(\boldsymbol{x}_{t+h}^{(k,m)},
         \boldsymbol{u}_{t+h}^{(k)})
    +\ell_f(\boldsymbol{x}_{t+H}^{(k,m)})
    \right]+\mathcal{C}_{\text{MPPI}}^{(k)},
    \label{eq:normflowsde_mppi_cost}
\end{equation}
where $\ell$ and $\ell_f$ are the running and terminal costs. The term
$\mathcal{C}_{\text{MPPI}}^{(k)}$ denotes the importance-sampling correction associated with perturbing the nominal control distribution; it also incorporates the quadratic control penalty in the standard MPPI formulation. State and obstacle constraints can be included as soft penalties in $\ell$ or as an infinite cost for invalid rollouts. Thus, $\widehat{J}_k$ is the Monte Carlo estimate of the objective $J(\boldsymbol{U}_t^{(k)};\boldsymbol{x}_t)$ for the $k$-th perturbed control sequence, augmented by the MPPI sampling correction.

The path costs are converted into normalized importance weights,
\begin{equation}
    w_k=\frac{\exp[-(\widehat{J}_k-\rho)/\lambda]}
    {\sum_{j=1}^{K}\exp[-(\widehat{J}_j-\rho)/\lambda]},
    \qquad \rho=\min_j\widehat{J}_j,
    \label{eq:normflowsde_mppi_weights}
\end{equation}
where the subtraction of $\rho$ improves numerical stability and the temperature $\lambda>0$ controls selectivity. A small $\lambda$ concentrates the update on the lowest-cost paths, whereas a large $\lambda$ averages more broadly over the sampled candidates. The nominal controls are then shifted toward perturbations that generated low-cost trajectories:
\begin{equation}
    \boldsymbol{u}_{t+h}\leftarrow\boldsymbol{u}_{t+h}
    +\sum_{k=1}^{K}w_k\delta\boldsymbol{u}_{t+h}^{(k)},
    \qquad h=0,\ldots,H-1.
    \label{eq:normflowsde_mppi_update}
\end{equation}

Only the first optimized input is applied to the plant, as the other receding-horizon control frameworks. At the next environment step, the horizon is shifted, the terminal input is initialized, and the sampling-and-integration procedure is repeated using the new state estimate. This receding-horizon feedback corrects model error and newly observed disturbances.

The integral form of NormFlowSDE is especially useful here. For each candidate control sequence, an SDE solver computes complete stochastic paths rather than only point predictions. MPPI then approximates its path integral with the same ensemble, so no additional uncertainty propagation or local linearization is required. The candidate and uncertainty rollouts are mutually independent and can be evaluated in parallel. Moreover, risk sensitivity and input smoothness can also be introduced.

\subsubsection{Validation on a Navigation Task}
We validate NormFlowSDE within an MPPI framework using a simulated differential-drive robot navigating spatially heterogeneous terrain in MuJoCo \citep{todorov2012mujoco}. The robot comprises a rigid base and two independently actuated wheels separated by a fixed track width. The MuJoCo simulation uses a time step of $2\,\mathrm{ms}$, while control commands are updated every $20\,\mathrm{ms}$. Each command specifies the desired forward and angular velocities:
\begin{equation}
   \boldsymbol{u}_t=[v_t^{cmd},\omega_t^{cmd}]^\top,\qquad
   v_t^{cmd}\in[0,2.2]\,\mathrm{m\,s^{-1}},\quad
   \omega_t^{cmd}\in[-3,3]\,\mathrm{rad\,s^{-1}}.
\end{equation}
The terrain is characterized by a spatially varying friction coefficient defined by the deterministic two-dimensional function:
\begin{equation}
\begin{aligned}
    \mu(x,y)=\text{clip}\;\bigl[&0.72+0.16\bigl(
    0.55\sin(0.72x)\cos(0.51y)+0.30\sin(1.31y+0.37x) \\
    &{}+0.15\cos(1.73x-0.44y)\bigr),\,0.48,\,1\bigr].
\end{aligned}
\end{equation}
where $\operatorname{clip}(z,a,b)$ restricts $z$ to the interval $[a,b]$.

After each control interval, stochastic perturbations are applied to the forward and yaw velocities. Their magnitudes increase in low-friction regions and during aggressive combinations of translation and rotation, representing unresolved wheel--ground interactions and slip. The observed state vector is
\begin{equation}
    \boldsymbol{x}_t=[p_x,p_y,\theta, v_f,v_l,\omega,\dot\phi_L,\dot\phi_R]^\top,
\end{equation}
where $(p_x,p_y)$ denotes the planar position, $\theta$ the heading angle, $v_f$ and $v_l$ the body-frame forward and lateral velocities, $\omega$ the yaw rate, and $\dot\phi_L$ and $\dot\phi_R$ the left- and right-wheel angular velocities, respectively.

The dataset comprises 300 trajectories, each containing 500 transitions and spanning $10\,\mathrm{s}$. The trajectories are split at the episode level into 210 training, 45 validation, and 45 test episodes, ensuring that transitions from a given rollout appear in only one subset. Each episode starts from a position sampled uniformly within the arena, $[-4,4]\times[-3,3]$, and a heading sampled uniformly from $[-\pi,\pi]$. Data are collected using a proportional waypoint-following controller augmented with temporally correlated random excitation to achieve broad coverage of the state--action space.

\paragraph{Open-Loop Dynamics Modeling}
NormFlowSDE is trained in two stages. First, the deterministic drift network is fitted by minimizing the mean squared error. The drift and diffusion networks are then optimized jointly using \ac{NLL}, a multiple-shooting continuity objective, and a path-level energy-score loss. Training uses 100-step trajectories spanning $2\,\mathrm{s}$, partitioned into five-step multiple-shooting segments.

Figure~\ref{fig:differential_drive_open_loop} shows the open-loop reconstruction of one test episode. The predictive mean captures the curved planar path and closely follows the reference trajectory. The 90\% predictive intervals generally contain the reference states or remain close to them. These intervals are narrow near the initial condition and gradually widen as uncertainty accumulates through recursive prediction without measurement correction. Despite this accumulation, the model captures the principal temporal variations in the rapidly changing states.

\subsection{CondStochInt in DPPO}
\subsubsection{CondStochInt Policy}
The CondStochInt control policy generates action chunk based on history observations and current state, as shown in Figure~\ref{fig:CondStochInt_control}. At the beginning of environment step $t=0$, the agent retrieves the sliding window of historical observations $O_{...:0}$. A condition network $C_\psi$ embeds these temporal observations into a low-dimensional embedding vector $c$, which provides context information for the generative process of the stochastic interpolant. Unlike the CondStochInt proposed for state estimation, where the inferred coarse trajectory in the latent space provides an informative basis for state estimation, they do not necessarily provide a direct mapping to the action chunk. Thus, the latent space $\mathcal{U}_0$ here is chosen to be a standard Gaussian distribution and is transformed into a high-fidelity action chunk $\mathcal{U}_1$ by numerically integrating the \ac{SDE} from $\tau = 0$ to $\tau = 1$:
\begin{equation}
    d\mathcal{U}_\tau = \left[ v_\varphi(\mathcal{U}_\tau, \tau; c) + g_0^2 S_\phi(\mathcal{U}_\tau, \tau; c) \right] d\tau + g_0 \sqrt{2\sigma_\tau} dW_\tau.
\end{equation}

The agent generates an action chunk $a_{0:H-1}$ in closed loop. Taking the actions, the environment updates the new observations $O_{1:H}$. To update the networks ($\varphi, \phi, \eta, \psi$) online using \ac{RL}, the generated action chunks are evaluated against a reward function $r$, which also considers the history and updated observations.

\subsubsection{Diffusion Policy Policy Optimization}
\ac{DPPO} is an on-policy reinforcement-learning framework for fine-tuning diffusion-based control policies that have been pre-trained from expert demonstrations \cite{ren2024diffusionpolicypolicyoptimization}. It combines the expressive action distribution of a diffusion policy with policy-gradient optimization, such as \ac{PPO} \citep{schulman2017proximalpolicyoptimizationalgorithms}. In order to use the \ac{PPO}, the likelihood of an action under the policy needs to be computed. It's easy for a simple Gaussian policy, but a diffusion policy generates actions through a multi-step denoising process, causing the likelihood calculation intractable. Therefore, the iterative denoising process is interpreted as an inner \ac{MDP}, where each step of this reverse-diffusion chain has an explicit Gaussian likelihood and can be used in \ac{PPO},while the interaction between the generated actions and the physical environment constitutes an outer \ac{MDP}. 

The conceptual idea of the \ac{DPPO} is to formulate diffusion-model sampling as a sequential decision-making process and optimizes the denoising transitions using a terminal reward \cite{black2024trainingdiffusionmodelsreinforcement}. Unlike a unimodal Gaussian policy, a diffusion policy can represent complex and multimodal conditional action distributions. This property is useful in contact-rich manipulation because several coordinated action sequences may constitute valid solutions for the same task state. \cite{ren2024diffusionpolicypolicyoptimization}.

Before \ac{RL} training, the diffusion policy is pre-trained on expert demonstrations through \ac{BC}. \ac{BC} is a supervised imitation learning approach that learns a policy by mimicking expert demonstrations without interaction with the environment. The objective is to reproduce the conditional distribution of expert action chunks, i.e.,$p_\varphi(a_{0:H-1}| s_{1:H})$. BC provides an important initialization for DPPO. \ac{RL} fine-tuning can then improve the policy further, compensate for imperfections or limited coverage in the demonstrations, and adapt it to states induced by its own closed-loop behavior.

The policy is optimized using \ac{PPO}, which maximizes a clipped surrogate objective that constrains the probability ratio between the updated and previous policy:
\begin{equation}
    r(\varphi) = \frac{\pi_\varphi(a| s)}{\pi_{\varphi_{\text{old}}}(a| s)}.
\end{equation}
Then the ratio is clipped so that the policy update is constrained within a trust region:
\begin{equation}
    L^{\text{CLIP}}(\varphi) = \mathbb{E}\left[\min\left(r(\varphi)\hat{A}, \, \text{clip}(r(\varphi), 1-\epsilon, 1+\epsilon)\hat{A}\right)\right],
\end{equation}
where $\hat{A}$ is an estimate of the advantage function \citep{schulman2018highdimensionalcontinuouscontrolusing} and $\epsilon$ controls the trust region around the previous policy. Applying the diffusion model in this procedure, the policy is calculated step by step,
\begin{equation}
    \pi_\varphi(a_t^{k-1} | a_t^k, s_t) = \mathcal{N}\big(a_t^{k-1};\, \mu_\varphi(a_t^k, k, s_t), \sigma_k^2 I\big),
\end{equation}
where $k$ is the diffusion step. By reindexing each denoising step as a transition in an inner MDP nested within the outer MDP interacting with the environment, one total update step unrolls into $K$ such inner transitions, yielding a single combined chain.

\subsubsection{Validation with Robotic Manipulation Task}
Dexterous manipulation tasks are quite suitable to validate the diffusion policies because of the contact-rich and the multi-modal nature of the tasks. We compare the CondStochInt with \ac{DDPM} as diffusion policies in a door-opening task, taking the environment "AdroitHandDoor-v2" from Gymnasium-Robotics \citep{gymnasium_robotics2023github, rajeswaran2018learning}. The environment provides a simulated robotic hand with 24 degrees of freedom, including 20 joint angles for the fingers and 4 for the palm. The state space includes the joint angles, joint velocities, and the position and orientation of the door handle and are in total 39-dimensional. The policies are supposed to control a 28-dimensional continuous action vector. 

Episodes are limited to 300 primitive environment steps. The dense reward supplied by the environment is used for both policy optimization and evaluation. A rollout is considered successful if the environment’s success entry becomes true at any point during the episode. THe length of generated action chunk is set to $H=4$ steps, taking one-step history because of the Markovian behavior. All four actions are executed before the policy replans, unless the episode terminates earlier. Consequently, one outer policy transition  corresponds to four primitive environment transitions. The rewards obtained from these four transitions are summed to form the reward for one outer-MDP transition.

\paragraph{Behavior Cloning Pre-training}
Both policies are first pre-trained by behavior cloning on the same demonstrations derived from the D4RL "door-expert-v2" dataset \citep{fu2020d4rl}. The prepared dataset contains 100 expert trajectories and 20,000 primitive transitions. We split them into 80\% for training and 20\% for validation. 

Four policies are evaluated under the same conditions: 
\begin{enumerate}
    \item CSI: both velocity and score networks are learned.
    \item FM: only velocity network is learned, and there is no stochastic term.
    \item SBM: the score network is learned, and there is no learned deterministic term.
    \item DDPM: discrete diffusion model is applied.
\end{enumerate}

The four policies are configurated similarly with approximatedly same number of network parameters. All methods take $20$ Euler–Maruyama integration steps during inference. Three seeds are used for different network initialization and thus produced different network parameters. Each policy was evaluated for 50 episodes per training seed using the same environment-reset seeds. No stochastic inference is calculated for comparing the pre-training results. Figure~\ref{fig:door_score_ablation} shows the success rate and return after \c{BC} pre-training.

\paragraph{DPPO Fine-tuning}
