# ALOHA simulated insertion (human demonstrations)

LeRobot-format snapshot of human ALOHA insertion demonstrations. It contains
50 episodes and 25,000 rows split across four Parquet shards. The state and
action arrays are consumed by the state-estimation experiments.

The local directory name and loader identify this as an
`aloha_sim_insertion_human` snapshot, but the original repository namespace,
Hub revision, and download command were not retained. These fields are marked
unknown in `provenance.yaml` and should be completed from the acquisition host
or shell history.

Binary shards are deliberately stored outside Git; their checksums are in the
provenance config.
