# SO-100 stacking

LeRobot v3 hardware dataset for a single SO-100 stacking task. The local
snapshot contains 56 episodes, 22,956 frames at 30 Hz, six-dimensional state
and action vectors, and metadata describing top and wrist video streams.

This repository did not retain the recording or download command, operator,
hardware calibration, or source revision. `provenance.yaml` records the facts
recoverable from `info.json` and marks the remaining fields unknown. Complete
those fields before using this as a published reproducibility artifact.

The Parquet payload and `info.json` are kept outside Git.
