# xArm Lift Medium

LeRobot-format xArm lifting dataset containing 800 episodes and 20,000 rows.
It includes state/action sequences, reward and terminal fields, timestamps,
and episode/frame/task indices.

The dataset name is recoverable from the directory, but the original namespace,
revision, and acquisition command are not present in this repository. They are
therefore explicitly marked unknown in `provenance.yaml`; update them from the
original download records rather than relying on the directory name alone.

The Parquet payload is stored outside Git.
